Deutung

Die Folie hält Wärmestrahlung zurück — genau das tun Treibhausgase in der Atmosphäre, nur ohne Folie.

Wichtiger Hinweis
Dieser Versuch zeigt nur das allgemeine Prinzip — eine Barriere hält Wärmestrahlung zurück. Er beweist nicht, dass genau CO₂ das tut.
