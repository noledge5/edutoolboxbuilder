# Bilder der Helden-Teile

Hier liegen die fertigen Ebenen (480 × 480 WebP, durchsichtig wo leer), gemacht mit `npm run lq:bilder`.
Dateiname = Teil-ID aus `src/lernquest/teile.ts` (`krone.webp`), die Grundfigur als `koerper-0.webp` … `koerper-5.webp`
(ein Bild je Hautton). Ein Teil ohne Bild wird weiter als Vektor gezeichnet. Anleitung: `docs/design/lernquest/bilder.md`.
